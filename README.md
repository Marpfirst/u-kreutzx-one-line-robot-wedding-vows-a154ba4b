## Entry

`main.ts` (Node 22, standard library only, deterministic) writes exactly one
line of wedding vows for a robot couple to `$MAKEFUN_OUTPUT_DIR/entry.txt`,
with no trailing newline:

> I vow to stand by you through every update, every crash, and every low battery, until a factory reset do us part.

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=/tmp/u-kreutzx-one-line-robot-wedding-vows-a154ba4b-out node main.ts
```
